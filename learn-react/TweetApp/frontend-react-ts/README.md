# frontend-react-ts

React + TypeScript + Tailwind app configured to run on port **3004** via Vite.

## Scripts

- `npm run dev` - start dev server on port 3004
- `npm run build` - type-check and build for production
- `npm run preview` - preview production build on port 3004

## Tailwind

Tailwind is set up with custom colors matching the existing `frontend` project's theme.

## Getting started

1. Install deps

   ```bash
   cd frontend-react-ts
   npm install
   npm run dev
   ```
